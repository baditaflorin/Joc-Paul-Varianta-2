# Joc Paul — Varianta 2

Un mic joc 3D de browser construit cu Three.js. Activează gaura neagră și atrage obiectele din camera de testare; apasă din nou pentru a le readuce.

## Joacă local

Deschide `index.html` într-un browser cu acces la internet sau pornește un server static din acest director, de exemplu:

```sh
python3 -m http.server 8000
```

Apoi vizitează `http://localhost:8000`.

## Comenzi

- Butonul **ACTIVEAZĂ GAURA** sau tasta **Space** pornește/oprește gravitația.
- Trage în scenă ca să rotești camera; folosește scroll pentru zoom.
- Butonul ♪ activează sunetele sintetizate.

Three.js este încărcat din jsDelivr, iar fonturile din Google Fonts.
